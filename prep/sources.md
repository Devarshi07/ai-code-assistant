# Further reading

These public pages informed the guides and the practice formats in this app. The questions, problems and guides in Debug Gym are original; none of these sources are copied. Platform documentation changes often, so check the date on a page before relying on a detail. Each line says what you'll find and why it's worth a look.

## How AI-assisted assessments and interviews work

- [HackerRank: AI-assisted interviews](https://support.hackerrank.com/articles/5821380141-ai-assisted-interviews): how the AI assistant appears in a live interview, which modes the candidate gets, and what the interviewer can watch while the candidate works with it.
- [HackerRank: AI-assisted tests](https://support.hackerrank.com/articles/1152916770-ai-assisted-tests): the recruiter's side of AI in online tests, including the No, Guarded and Unguarded levels and which modes each level unlocks.
- [HackerRank candidate help: the AI assistant in tests](https://candidatesupport.hackerrank.com/articles/7634558376-ai-assistant-in-tests): the same feature from the candidate's side, including what the assistant will and won't help with.
- [HackerRank: AI usage summary](https://support.hackerrank.com/articles/1773201418-ai-usage-summary): how a report grades the way a candidate used AI, with letter grades backed by excerpts from the conversation.
- [HackerRank knowledge base: the AI assistant in interviews](https://hackerrank-knowledge-base.help.usepylon.com/articles/4698145256): more detail on modes, approvals for agent actions, and model choice.
- [HackerRank knowledge base: the context window](https://hackerrank-knowledge-base.help.usepylon.com/articles/8899388716): why long conversations get trimmed, and how the context meter works.
- [HackerRank: preparing for an AI-assisted IDE assessment](https://www.hackerrank.com/writing/how-to-prepare-hackerrank-ai-assisted-ide-technical-assessment-interview-2025): the platform's own advice on getting familiar with the environment and on how rounds are run.

## Test flow, scoring and integrity

- [Answering coding questions](https://candidatesupport.hackerrank.com/articles/9623161883-answer-coding-questions): the candidate's coding screen, from the language list and editor settings to running code and reading results.
- [What is evaluated when a test times out](https://candidatesupport.hackerrank.com/articles/3576626591-evaluation-of-a-question-during-test-time-out): the rule for which version of your code counts when the timer runs out.
- [Frequently asked questions during a test](https://candidatesupport.hackerrank.com/articles/2859650598-frequently-asked-questions-during-the-test): timer warnings, the theme switcher, and what to do when something goes wrong.
- [Proctoring for tests](https://support.hackerrank.com/articles/1079706165-proctoring-hackerrank-tests): what Secure Mode enforces, such as full screen, blocked copy and paste, and a single monitor.
- [Proctor Mode](https://support.hackerrank.com/articles/5663779659-proctor-mode): webcam snapshots, screenshots and how a session is labelled suspicious or not.
- [AI plagiarism detection](https://support.hackerrank.com/articles/8000786908-ai-plagiarism-detection): the behaviour signals behind plagiarism flags, such as code deleted and replaced in one go, outside pastes and keystroke replay.

## Question formats beyond algorithms

- [Question types for projects](https://hackerrank-knowledge-base.help.usepylon.com/articles/1570281449): front-end, back-end and full-stack project questions in a full IDE.
- [Database engineer questions](https://hackerrank-knowledge-base.help.usepylon.com/articles/8826242281-database-engineer-questions): how SQL questions are set up and scored, including whether row order matters.
- [Code review questions](https://hackerrank-knowledge-base.help.usepylon.com/articles/4262355406-code-review-questions): questions where you comment on a diff instead of writing code.
- [REST API (Intermediate) skill](https://www.hackerrank.com/skills-directory/rest_api_intermediate): the skills a REST API certification covers.
- [RealWorld example apps](https://github.com/gothinkster/realworld): an openly licensed API specification with a test collection, useful for practising building a complete API.
- [SQL Murder Mystery](https://mystery.knightlab.com): a free puzzle that teaches joins and filtering by solving a story.

## AI-assisted rounds at specific companies

- [PracHub: AI coding interview guide](https://prachub.com/resources/ai-coding-interview-guide): an overview of AI-assisted coding rounds and what interviewers evaluate.
- [PracHub: Meta's AI-assisted coding round](https://prachub.com/resources/meta-ai-coding-interview): the multi-part, multi-file format of that round.
- [PracHub: HackerRank's AI interviewer](https://prachub.com/resources/hackerrank-chakra-ai-interview-guide-2026-voice-questions-transcript-scoring-and-candidate-reports): how a voice AI interviewer runs a round, and how its scoring report is organized.
- [PracHub: AI-assisted question list](https://prachub.com/categories/coding-and-algorithms/ai-assisted): reported question themes for AI-assisted rounds.
- [PracHub: machine learning engineer questions](https://prachub.com/positions/machine-learning-engineer): reported ML engineer interview themes, from ML coding to system design.
- [interviewing.io on Meta's AI round](https://interviewing.io/blog/how-to-use-ai-in-meta-s-ai-assisted-coding-interview-with-real-prompts-and-examples): an article with example prompts for that round (not reviewed for this app).
- [Reddit: an ML engineer interview with HackerRank's AI interviewer](https://www.reddit.com/r/leetcode/comments/1t62dat/hackerrank_chakra_ml_engineer_interview/): a candidate's account of an ML round (it couldn't be read automatically when these guides were written).

## Using these sources well

Read the platform pages for the rules of the format, and the candidate accounts for what it feels like. Then practise the format here instead of memorizing reported questions: companies rotate their questions, but the skills they reward stay the same.
